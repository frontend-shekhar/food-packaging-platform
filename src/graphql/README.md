# GraphQL Directory

This directory contains all the GraphQL queries and mutations required for the project. It is structured to keep the GraphQL operations organized and maintainable.

## Usage

1. **Adding Queries**:

   - Create a new file in the directory for each distinct query.
   - Name the file according to the data or operation it is fetching, e.g., `getUserById.graphql`.

2. **Adding Mutations**:
   - Create a new file in the directory for each distinct mutation.
   - Name the file according to the operation it is performing, e.g., `createUser.graphql`.
