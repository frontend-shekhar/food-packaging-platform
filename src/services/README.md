# Services Directory

This directory contains all the service files related to API calls and interactions with external services.

## Purpose

- **API Integration**: The `services` directory centralizes API calls and service-related functions, promoting better organization and maintainability of network requests.

## Guidelines

- **File Naming**: Each file should be named descriptively based on the type of services it handles. For instance, `authService.ts` is for authentication-related API interactions.
- **API Calls**: Keep API calls modular and reusable. Each service file should export functions that encapsulate specific API interactions.
- **Error Handling**: Ensure proper error handling is implemented in your API calls to manage exceptions and API errors gracefully.
