# UI Components Directory

This directory contains all the UI components used in the application.

## Purpose

- **UI Components**: These are components that are primarily responsible for the presentation and layout of the application. They are usually styled and designed to create a consistent look and feel across the application.

- **ShadCN UI Components**: This directory includes all UI components related to ShadCN. These components are used to build the user interface and are generally reusable across different parts of the application.

## Guidelines

- **Naming**: Name components clearly and descriptively to reflect their purpose.
- **Reusability**: Ensure components are reusable and follow consistent styling practices.
